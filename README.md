# 🚀 Lunar Lander Neural Network Controller

> A neural network built **entirely from scratch using NumPy** — no PyTorch, no TensorFlow — to control a lunar lander simulation by predicting thruster and turning velocities from positional inputs.

---

## 📌 Project Overview

This project implements a fully connected feedforward neural network trained via backpropagation to act as an autonomous controller for a lunar lander. Given the lander's X and Y position, the model predicts the optimal thruster and turning velocities needed to navigate safely.

The entire training loop — forward pass, loss calculation, backpropagation, and weight updates — is implemented manually using only NumPy, making this an excellent demonstration of deep ML fundamentals.

---

## 🧠 Neural Network Architecture

```
Input Layer (2)  →  Hidden Layer (16 neurons, Sigmoid)  →  Output Layer (2)
```

| Layer         | Neurons | Activation |
|---------------|---------|------------|
| Input         | 2       | —          |
| Hidden        | 16      | Sigmoid    |
| Output        | 2       | Sigmoid    |

- **Inputs:** X position, Y position (normalized)
- **Outputs:** Thruster velocity, Turning velocity (denormalized after prediction)
- **Loss Function:** Root Mean Squared Error (RMSE)
- **Optimizer:** Gradient Descent with Backpropagation
- **Learning Rate:** 0.1
- **Epochs:** 100

## 🔍 File Descriptions

### `Individual_Neural_network_.ipynb`
The core training notebook. Contains:
- Data loading and exploratory analysis
- Input normalization (z-score standardization)
- 80/20 train/validation split
- Manual forward pass and backpropagation loop
- RMSE tracking over 100 epochs
- Training vs Validation RMSE plot
- Neural network architecture visualisation

### `NeuralNetHolder.py`
A clean, production-style inference class that:
- Stores the 16 hardcoded trained weights
- Applies min-max normalization to incoming inputs
- Runs a full forward pass (input → hidden → output)
- Denormalizes outputs back to real velocity values
- Applies log-odds transform for final prediction output

## 🚀 How to Run

### 1. Clone the repository
```bash
git clone https://github.com/bhushangavali/lunar-lander-nn-numpy.git
cd lunar-lander-nn-numpy
```

### 2. Install dependencies
```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

### 3. Train the model
```bash
jupyter notebook Individual_Neural_network_.ipynb
```

### 4. Run inference
```python
from NeuralNetHolder import NeuralNetHolder

model = NeuralNetHolder()

# Pass X and Y position as a tuple string
prediction = model.predict("(0.5, 0.3)")

print("Predicted velocities:", prediction)
# Output: [x_velocity, y_velocity]
```
